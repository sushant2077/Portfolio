# Sushant Budhathoki Chhetri — Portfolio

A fully responsive, static portfolio website tailored to both:

- IT / Cybersecurity / IT Support roles
- Hospitality / Venue Operations / Leadership roles

## What is included

- Modern dark neon-glass design
- Floating responsive navigation
- Smooth reveal animations
- Mouse glow and interactive tilt effects
- Profile photo
- IT & cybersecurity skills
- Hospitality & leadership skills
- Shito-Ryu Karate black belt
- Cybersecurity projects
- Employment history with month/year only
- Education and training
- Netlify contact form
- Downloadable IT resume
- BIT completion letter

## Run locally

No Node.js or build step is required.

### Simple option

Open `index.html` directly in your browser.

### Better option

From this folder:

```bash
python -m http.server 8000
```

Then open:

http://localhost:8000

## Deploy to GitHub + Netlify

1. Create a new GitHub repository.
2. Upload everything inside this folder.
3. Commit and push.
4. In Netlify choose **Add new project → Import an existing project**.
5. Connect GitHub and select the repository.
6. Build command: leave blank.
7. Publish directory: `.`
8. Deploy.

The contact form is already configured with Netlify Forms.

## Important content note

The site is intentionally positioned as a dual-career portfolio. The hero and project sections lean toward IT/cybersecurity, while the experience and capabilities sections preserve hospitality leadership experience.
